## Adopted technologies
Custom website layout realized with [Bootstrap](https://getbootstrap.com/), which provide popover behaviour script too.
[translations.js](translations.js) provides a dictionary for English and Italian frontend texts plus the script meant to switch them when site language change is triggered through navbar buttons.
See [this other web app overview](https://github.com/Organisn/Web-Curriculum-Vitae-Portfolio/blob/main/README.md) to learn how to install and configure PHP and PHPMailer on your Windows system.
